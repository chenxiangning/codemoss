设计定稿摘要（实现前契约）

L0 Workspace root：会话 cwd，永远在 allowlist。
L1 Session allowlist：用户明确 grant 的额外根；映射 Claude --add-dir / Codex sandbox roots / Shared host path gate。
L2 Tool approval：在已 allow 的根内再问写/执行（现有 ApprovalRequest）。
L3 OS privacy：仅 macOS 在 TCC 敏感位置提示；Win/Linux 不伪造系统弹窗。

范围枚举：once（仅本次 tool）· session（当前会话）· workspace（本 workspace 持久）· 禁止默认 global always。
路径规则：canonical + 拒绝 symlink 逃逸；Windows 规范化盘符与 \；Linux 大小写敏感；macOS 默认 case-insensitive 比较。
触发：工具 error 含 outside allowed working directories / path not allowed → 合成 DirectoryGrantRequest（与 file/command approval 分 kind，禁止静默吞掉）。
