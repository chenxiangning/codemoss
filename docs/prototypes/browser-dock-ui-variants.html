浏览器 Dock — 10 个变体 R2 · 紧凑向

以「紧凑单行」为主轴做质感分层：发丝线、内高光、mono 微标注、毛玻璃、状态光晕。功能集不变：标签 / URL / 打开 / 定位 / 关闭 / 关联上下文。

01

磁吸胶囊岛

所有控件收成一颗胶囊悬浮在内容上方，毛玻璃 + 内高光。不用时视觉零占地，像 Dynamic Island。
