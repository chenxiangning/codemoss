网页摘录 · 折叠发送 8 套

上一版 V1 和 V10 几乎没差。

V1 只画「发送后幕布长什么样」——细线折叠条。V10 多画了发送前对话框里那一行 token，发送后还是同一条折叠。所以看起来像重复。

下面 8 套都走同一条主路径：对话框先挂摘录 → 点发送 → 用户气泡 + 折叠条落幕布。差的是折叠形态、展开时机、token 能不能拆、发完后对话怎么接。
