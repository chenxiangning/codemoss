十个方向，专门治那片空白。

现在的列表页把一张 280px 卡片扔进整屏浅色径向渐变里。功能都在，画面却像没装完。 下面 10 个 HTML 都按真实产品信息架构来：Architect / Spotlight / File、元素/文件/节点、挂会话、项目知识地图。 双击即可打开，用来拍板「下一版长什么样」。

现况病根

网格 `auto-fill 280px` + 无缩略图 + 无第二视觉层。一张卡时，80% 视口是空的。

不要做的

不要再给卡片加彩虹顶条、emoji、紫渐变。空要用构图填，不是再堆一排统计数字。

怎么选

1 张画布也成立 → 03 / 04 / 05 / 08。库长大了还好看 → 01 / 02 / 07。气质重选 → 06 / 10。
